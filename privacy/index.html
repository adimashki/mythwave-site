MYTHWAVE STUDIOS / WEBSITE INFORMATION

Privacy Policy

Last updated: 11 September 2026. This notice covers the MythWave Studios website only. Each game has its own privacy information, listed under Game policies.

What this website collects

Nothing that identifies you. The website has no accounts, sign-in, checkout, contact form, advertising, analytics, or tracking. We do not build profiles of visitors.

Hosting

The website is a set of static pages served by our hosting provider, GitHub Pages. Like most hosting services, it may record technical information such as your IP address in server logs for security and abuse prevention. That processing is handled by the hosting provider under its own privacy policy, and we do not use those logs to identify visitors.

External services

Store buttons, social links, and trailer links may take you to other websites, such as the App Store, Google Play, or a video platform. Those services have their own privacy practices, and this notice does not cover them.

Children

The website introduces games made for different audiences, including children. It does not collect personal information from anyone, including children. The privacy practices of each game are explained separately on that game’s policy page.

Changes to this notice

If we add features that change how the website handles information, for example a newsletter or analytics, we will update this notice and the date above before those features go live.
